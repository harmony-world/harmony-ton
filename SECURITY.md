# Security

HARMONY handles real donations, so please report vulnerabilities **privately**.

- Use GitHub's private vulnerability reporting: **Security → Report a vulnerability** in this repository.
- Include what you found, how to reproduce it, and what an attacker could do with it.
- Please don't open a public issue or post details anywhere until we've shipped a fix.

What's in scope: the contracts in `contracts/harmony/`, the backend API and bot, the Mini App.

The anti-fraud and moderation internals are not part of this repository by design; if an audit needs them, say so in your report.
